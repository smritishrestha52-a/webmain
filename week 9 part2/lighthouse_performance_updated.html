The audit also displayed the Network Dependency Tree and DOM-size audits as items to inspect. The screenshot does not establish that these items are failing or that fixes have already been applied, so they are recorded here as review opportunities only.

Step 4 · Recommended optimization actions

  1. Review CSS and JavaScript resources that block the first render.
  2. Defer non-critical JavaScript when it is safe to do so.
  3. Remove unused CSS or JavaScript where appropriate.
  4. Review the Network Dependency Tree and reduce unnecessary resource-loading chains.
  5. Keep the HTML structure efficient and avoid unnecessary DOM elements.
  6. Run Lighthouse again after making changes to compare the results.
