Good to know

Frequently asked questions.

A few answers before you begin.

Is BiHE.COM a real matchmaking service?

No. This is a front-end educational prototype created for a web programming project.

Are the profiles real?

No. All names, profiles and details shown on this website are sample data.

Can I search for a specific match?

Yes. You can test the search filters by gender preference, age range, religion and location.

Does the compatibility calculator predict relationships?

No. It is a small entertainment feature that demonstrates JavaScript interaction.

Can I create a real account?

The sign-up form demonstrates front-end validation only. It does not create or store real accounts.
