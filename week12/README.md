# Week 12 — React State Studio

This folder contains the Week 12 practical work for Web Programming K0126_002.

## Included tasks

### PDF page 33 — Code Challenge: Counter with History
- Counter starts at 0.
- `+1`, `-1`, `Reset`, and `Undo` buttons.
- Keeps only the latest five values in history.
- Undo restores the previous value and removes the latest history entry.
- Uses two React state variables: `count` and `history`.

### PDF page 34 — Homework: Interactive Shopping Cart
- Five products with names, prices, and image URLs.
- Add to cart and remove from cart.
- Quantity `+` and `-` controls for each item.
- A separate `ShoppingCart` component.
- Cart item count and total price are calculated from cart state.

### Relevant examples for the personal page
- State vs props.
- Functional state updates.
- Immutable object and array updates.
- Lifting state up to a parent component.

## Important
The project is a single `index.html` file. React 18 and Babel are loaded from public CDNs, so an internet connection is required when opening the page. No `npm install`, terminal, or GCC is needed.
